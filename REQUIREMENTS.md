# Requirements

## Hardware

### CPU: 
No specific high-performance requirements; most inference is handled by the LLM API.

### Storage: 
~500MB for the tool and enough storage for two repository clones.

### Network: 
Active internet connection required for LLM API calls and cloning repositories.

## Software

### Operating System: 
Linux or macOS (tested only on Ubuntu 22.04).


### Environment:
- Rust Compiler (Stable version)
- Python 3.10+ (dependencies listed in `pyproject.toml`)
- OpenAI API access.
